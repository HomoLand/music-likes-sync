# Likes Sync 用户指南

Likes Sync 在你的电脑或家庭服务器本地运行，不需要注册额外的产品账号。它以 Apple Music 的“喜欢的歌曲”为可信源，将新增和删除意图同步到 QQ 音乐与网易云音乐。

## 第一次使用

1. 打开“连接管理”，分别连接 Apple Music、QQ 音乐和网易云音乐。
2. 在“同步规则”选择“以 Apple Music 为准”。
3. 在“同步预览”运行检查，先处理需要人工判断的歌曲。
4. 确认新增后执行写入，再检查三端一致性。
5. 在“自动同步”开启定时任务。自动任务只处理新增，删除始终需要人工确认。

## 人工复核是什么意思

复核时，Apple Music 版本是判断基准。每个 QQ 音乐或网易云音乐候选都需要单独判断：

- **可以，保留**：候选能够代表 Apple Music 中喜欢的那条录音。目标平台保持不变，不会新增或删除。
- **不可以，替换**：候选不是你要的版本。系统会寻找并新增 Apple Music 对应版本；原候选只会进入待删除队列，仍需再次确认才会真正删除。

试听按钮最多播放 30 秒。若平台试听片段可可靠对齐，切换平台时会尽量保持在同一段音乐位置。

## 删除保护

执行真实删除前，Likes Sync 会创建带校验信息的本地恢复点。删除必须单独输入确认文本，自动同步不会绕过这一规则。

## 凭据和隐私

- 平台登录凭据只保存在运行 Likes Sync 的本机状态目录。
- 页面不会展示完整 Cookie、Token 或 API Key。
- AI 只接收最小化的歌曲证据，平台原始响应和凭据不会发送给模型。

平台登录和故障排查见 [PROVIDERS.md](./PROVIDERS.md)。
